数字孪生引擎

状态单一来源

环境与出力计算

仿真时刻以秒计，曲线按分钟定位并在相邻记录之间线性插值。没有自定义曲线时使用内置日曲线。

wind_kw = wind_available_power(wind_speed, wind_capacity)
pv_kw = pv_available_power(irradiance, air_temp, pv_capacity)
available_renewable_kw = wind_kw + pv_kw
风机切入 3 m/s额定风速 15 m/s切出 30 m/s光伏温度修正

功率平衡与网络量

内置嵌入式平衡模型替代外部潮流内核，输出收敛标志、迭代次数和不平衡量。

residual = load - wind - pv - diesel - battery
tie_flow = residual（并网断路器合位且电网可用）
mismatch = load - wind - pv - diesel - battery - tie_flow
频率 47～52 Hz 限幅母线电压联络线相角

储能 SOC

储能功率为正代表放电，负值代表充电。每个步长按能量容量积分，并将 SOC 限制在 10%～95%。

soc ← clamp(soc - battery_kw × Δt / 3600 / energy_kwh, 0.10, 0.95)

设备投运与拓扑

Web 可直接切换设备投运状态；拓扑节点退出或相关支路断开时，联锁逻辑会把孤岛设备置为退出。

node.run = false → device.run = false
edge.closed && edge.run → 允许设备接入

仿真时钟

支持启动、暂停、单步、归零和速度调整。仿真时间按 24 小时循环，历史最多保留 600 条记录。

模型驱动

模型 JSON 示例

{
  "name": "风储微网",
  "devices": [
    {"id": "wind-1", "type": "wind", "rated_kw": 80, "run": true},
    {"id": "pv-1", "type": "pv", "rated_kw": 60, "run": true},
    {"id": "diesel-1", "type": "diesel", "rated_kw": 180, "run": true},

  "topology": {"nodes": [], "edges": []},
  "curves": {"weather": [], "load": [], "diesel": [], "battery": []}
}

导入处理

  • JSON：读取 devices、topology、curves、points、metadata。
  • ZIP：优先识别 model.json / manifest.json；否则从 model.e、curves.json 等文件恢复设备和拓扑。
  • E-file：解析模型块，识别节点、支路、开关、风机、光伏、柴发、储能和负荷。
  • 设备类型别名会统一到 wind、pv、diesel、battery 等运行族。
  • 导入完成后清空历史和告警，重建运行点；IEC 104 桥接同步重建。
容量优先使用设备 rated_kw / rated_capacity / p_max；没有对应设备时使用内置演示容量。

曲线字段

每行至少包含 minute 或 time

weather / load

weather 支持 wind_speed_mps、solar_irradiance_w_m2、air_temp_c、load_kw；load 可单独覆盖负荷。

[{"minute":0,"wind_speed_mps":7,"solar_irradiance_w_m2":0,"air_temp_c":-20,"load_kw":160}]

diesel / battery

diesel 使用 diesel_kw 作为柴发目标出力；battery 使用 battery_kw 作为储能功率目标，正值放电。

diesel: [{"minute":0,"diesel_kw":120}]
battery: [{"minute":0,"battery_kw":-20}]

SCADA / IEC 104

通过 D:\codex\scada\server\iec104_server.py 的 IEC104Server 发布实时监视点并回调遥控命令。

scdfe_s 适配

点类与用途

YC11+频率、电压、负荷、风光柴发、储能、联络线、SOC、相角；导入设备后增加设备出力点。
YX4+并网断路器、柴油机、储能、电网可用；导入设备后增加设备运行状态点。
YK3并网断路器、柴油机、储能遥控。Web 和 IEC 104 都可触发。
YT0当前基础模型不生成遥调点；系统范围不包含 AGC/PAS 调节功能。
点表生成会写入 scdfe_s 的 fes_yc_define、fes_yx_define、fes_yk_define、fes_yt_define 以及 fes_channel_iec104_point_define。

实时发布链路

  1. 服务启动时由 ScdfeIEC104Bridge 加载 IEC104Server，并按当前运行点注册监视点。
  2. 数字孪生每次状态变化后调用 publish，主动上送 YC/YX，传送原因为 SPONTANEOUS。
  3. IEC 104 YK 回调进入 DigitalTwin.apply_command，改变并网、柴发或储能状态。
  4. 模型导入或点表生成后停止旧桥接、重建点、按原运行状态重新启动。
  5. Web 可查询监听地址、连接数、最新上送序号和最后错误。

scdfe_s 一键生成

模型管理 → 一键生成实时点表

RTU

默认 RTU ID 为 104，名称为“模型名 数字孪生”，通道类型为 iec104。

地址

YC 从 0x4001、YX 从 1、YK 从 0x6001、YT 从 0x6201 开始顺序映射。

上送

YC/YX 默认 1000 ms 上送周期；YK 采用 DIRECT 命令模式。

操作顺序

  1. 打开“模型管理”，导入 JSON、ZIP 或 E-file。
  2. 点击“一键生成实时点表”，确认 YC/YX/YK 统计。
  3. 在“曲线设置”修改环境或设备曲线并保存。
  4. 在“设备与拓扑”投退设备或更新拓扑。
  5. 在“SCADA / IEC 104”检查点值和服务连接。
  6. 在总览页用仿真时钟启动、暂停、单步或调整速度。

依赖与限制

部署前应确认

外部依赖

IEC 104 桥接依赖 D:\codex\scada\server\iec104_server.py 及 scdfe_s 数据库 schema。依赖不可用时 Web 仿真仍可运行，但 IEC 104 显示不可用。

计算内核

潮流部分为内置嵌入式功率平衡模型，提供工程演示所需的频率、电压、相角和收敛状态；它不是完整的 AC/DC 网络求解器。

数据语义

储能功率正值表示放电；联络线潮流正值表示从外部电网购电。曲线时间单位为分钟，仿真时间按 24 小时循环。
